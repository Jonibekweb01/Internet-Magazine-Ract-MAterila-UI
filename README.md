# 🛍️ Internet Magazine

A modern e-commerce style web application built with 
React.js and Material UI, showcasing product listings
and shopping interface.

## 🚀 Features
- Product listing and grid layout
- Material UI components
- Responsive design
- Clean shopping interface
- Category filtering

## 🛠️ Tech Stack
- React.js
- Material UI (MUI)
- JavaScript (ES6+)
- CSS
